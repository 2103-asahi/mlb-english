Tampermonkeyスクリプトでコピーしたクリップのjsonを貼り付けてください。

元動画を開く ・ 動画を小窓で開く

動画を見ながら、字幕を見ずに自分の言葉で実況・感想を英語で書いてみてください。書き終えたらAIが実際の実況と比較してフィードバックします。

設定

自分実況フィードバックにはGemini APIキーが必要です。Google AI Studioで取得したキーを貼り付けてください。このキーはこの端末のブラウザ内にのみ保存され、どこにも送信されません（Gemini API呼び出し時のみ使用）。

PC/スマホ同期（Supabase）

Supabaseのプロジェクト設定 → API にある「Project URL」と「anon public key」を貼り付けてください。両方の端末で同じ値を設定すると、クリップや単語帳が自動的に同期されます。
